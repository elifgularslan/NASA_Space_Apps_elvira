# Space Story 🚀

### Their missions may end, but their stories live on.

A story-driven educational game about the spacecraft and scientific equipment humanity has left on the Moon, Mars, and beyond.

Discover hidden explorers, recover their stories, and build your own mission archive.

🎮 **[Play Space Story](https://nasa-space-apps-elvira-weld.vercel.app/)**

Built by **Team ELVIRA** for the **NASA Space Apps Challenge 2026**.

---

## 🌌 The Challenge

Space exploration often brings attention to missions that are still active. Yet retired rovers, landers, probes, and scientific instruments helped build the knowledge we rely on today.

For the **NASA’s Discarded Equipment Storytelling** challenge, we wanted to make these histories accessible and engaging for younger audiences and casual space enthusiasts.

Our starting questions were:

- Why were these machines sent into space?
- What did they discover?
- What scientific legacy did they leave behind?

**Space Story turns these questions into an interactive journey of discovery.**

🔗 [Read the challenge](https://www.spaceappschallenge.org/2026/challenges/nasas-discarded-equipment-storytelling/)

## 🪐 Explore Three Sectors

| Sector | Discoveries |
| --- | --- |
| **The Moon** | Apollo Lunar Module, Lunar Roving Vehicle, ALSEP scientific package, Surveyor |
| **Mars** | Sojourner, Spirit, Opportunity, Viking 1 and 2, Phoenix, InSight, Ingenuity |
| **Deep Space** | Dawn, NEAR Shoemaker, Pioneer 10 and 11, Kepler |

The game features **13 search scenes and 17 collectible cards**. Some scenes contain two mission targets.

## 🎮 How to Play

1. Click **Space Story** to start the introduction with sound.
2. Follow the story, enter your explorer name, and choose a sector.
3. Read the mission briefing and enter the search area.
4. Find the target spacecraft hidden in the illustrated scene.
5. Use the optional **radar hint** if you need help.
6. Unlock a mission card and flip it to discover its story.
7. Collect every artifact to complete your expedition and unlock the final certificate.

### Radar Hint

The radar is available **once per scene** and lasts **five seconds**.

Move your pointer across the scene: the signal becomes stronger and the beeps become faster as you approach a target.

### Mission Cards

Each recovered artifact unlocks a collectible card containing:

- A real NASA photograph and image credit.
- Mission name, dates, and location.
- The purpose of the spacecraft or equipment.
- Its scientific contributions and a short story.
- Links to NASA sources.

Undiscovered cards appear as silhouettes in the field archive. Recovered cards can be reopened through the archive or **My collection** in the sidebar.

## ✨ Features

- Retro pixel-art environments.
- Story-driven exploration across three sectors.
- Hidden-object missions with single and paired targets.
- Collectible cards with reversible information views.
- NASA-based mission stories and credited photographs.
- Proximity radar with adaptive audio feedback.
- Sector completion indicators.
- A final expedition certificate and return-to-Earth sequence.
- Separate music and sound-effect volume and mute controls.
- Sidebar collection access and a restart option.

## 🔬 Scientific Context

The search scenes are stylized illustrations, not geographic maps or exact reconstructions of actual landing sites.

Spacecraft shown together may have operated in different locations. The Deep Space scenes do not represent a shared physical destination.

The educational cards explain the real historical examples, destinations, and scientific contributions using NASA sources. Authentic NASA photographs are presented separately from the pixel-art illustrations.

## 💻 Run Locally

Install a Node.js version compatible with the repository’s Vite version.

```bash
git clone https://github.com/elifgularslan/NASA_Space_Apps_elvira.git
cd NASA_Space_Apps_elvira
npm install
npm run dev
```

Open the local URL printed in the terminal.

On Windows PowerShell, if execution policy blocks `npm.ps1`, use:

```powershell
npm.cmd install
npm.cmd run dev
```

### Available Commands

```bash
npm run dev       # Start the development server
npm run build     # Build the production version
npm run preview   # Preview the production build
npm run lint      # Run code checks
```

## 💾 Progress and Audio

Game progress is stored in **sessionStorage**. It survives refreshes within the same tab session but is not a permanent save.

Confirming a player name starts a fresh expedition. The restart option clears progress.

Audio settings are stored in **localStorage**.

The title-screen interaction starts the introduction with sound, since browsers may restrict audible autoplay before user interaction.
